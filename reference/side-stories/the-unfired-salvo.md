# The Unfired Salvo — in-progress standalone reference

Source: [Chapters One–Four](../../side-stories/the-unfired-salvo.md). These events are **proposed standalone continuity**; main-novel placement is unestablished. This reference covers only the four chapters present in the public reading copy and contains spoilers for them.

At Verath Station, Imperial forces detain five Terran civilian freighters, including Captain Mara Venn’s *Aster Vale*. A sealed consignment contains a Varanthi authentication fragment. Commander Elias Damar commands the Terran frigate *Peregrine*; Commodore Anika Rell later brings a task group aboard the cruiser *Meridian*. Admiral Severin Caul commands the Imperial force, and Minister Helena Sorn negotiates on Terra’s behalf. The standoff escalates after Imperial fire disables the frigate *Cairn*. Verath controller Amira Solvek insists on preserving civilian authority and independent records.

The chaptered, unfinished source is kept separate from the seven-chapter main novel. Later material awaiting review is not represented as accepted story or main-novel canon.
